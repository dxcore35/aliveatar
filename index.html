Drop the tag. Drive it from anywhere.

A web component in the page, a command in your shell, an MCP tool for an AI agent — MCP is the standard way a model calls a tool, so Claude can move the face itself.

in your pageindex.html
<script type="module" src="avatar-motion/src/avatar-motion.js"></script>

<avatar-motion
  seed="reception-01"
  state="listening"
/>
in your appagent.js
avatar.send({ type: 'state', state: 'thinking' })
avatar.send({ type: 'tool.start', name: 'find_slot' })
avatar.send({ type: 'speech.attach', stream })
from a terminalcli
$ avatar state listening
$ avatar random kind=customer
$ avatar options
from an ai agentmcp
$ claude mcp add avatar -- bun mcp/server.js
